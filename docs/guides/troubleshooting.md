# Troubleshooting

| You see | Do this |
|---|---|
| Mac: "could not verify … free of malware" | **Done** → **System Settings** → **Privacy & Security** → **Open Anyway** |
| Windows: "Windows protected your PC" | **More info** → **Run anyway** |
| "The helper couldn't be installed" | Check your internet, then start Jobcu again |
| Jobcu's window closes or says "stopped because of a problem" | Start it again; if it repeats, send Utku a screenshot |
| "Jobcu couldn't close the older version" | Close other Jobcu windows (or restart the computer), then start again |
| Browser didn't open | Open `http://127.0.0.1:8765` in your browser |
| "Jobcu's engine isn't answering" | Jobcu's window was closed: start Jobcu again |
| "didn't accept the key" | Copy the whole key again → **Replace** → **Save** → test |
| "doesn't know this model name" | **Load model list** and pick one |
| "AI limit reached, continuing more slowly" | Normal on a free allowance, just wait |
| "allowance is used up" / "free requests are used up" | Try again tomorrow |
| Few or no jobs | Choose **1 week**, a wider place, or more job types |

Still stuck? Send Utku a screenshot (with no keys or personal details visible).
